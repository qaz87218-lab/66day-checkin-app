# 66 自律 V2

一個以「現實升等」為核心的長期自律 PWA。

## V2 主要變更

- 取消 66 天上限：自律天數無限累加；一天完成至少一項任務即計入。
- 每個任務獨立計算：累積完成天數、目前連續天數、最佳連續天數。
- EXP / Level 系統：每級需求逐步增加，Lv.100 起每級固定 2,080 EXP。
- 階級稱號：Lv.1～Lv.100 逐步解放 RPG 式稱號。
- 連續里程碑獎勵：7 / 30 / 66 / 100 / 365 天提供額外 EXP。
- 自訂任務：可選 1～5 星難度，對應 10～50 EXP；自訂任務每日基礎 EXP 上限 200。
- 舊版資料自動相容：沿用原本 localStorage key，保留既有每日任務勾選與筆記紀錄。
- 自訂任務移除採封存：歷史紀錄與 EXP 不會因刪除任務而消失。

## 升級 EXP

- Lv.1 → Lv.2：100 EXP
- 每級需求 +20 EXP
- Lv.100 起：每級固定 2,080 EXP

## 資料

所有資料仍儲存在瀏覽器 localStorage，可從設定頁匯出 / 匯入 JSON 備份。
