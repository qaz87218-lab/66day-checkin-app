# 66 自律 V3

一個以「現實升等」為核心的長期自律 PWA。66 天是第一個重要里程碑，不是終點。

## V3 主要變更

- 預設任務與自訂任務都可以刪除。
- 刪除採「從每日清單移除、歷史保留」：過去的完成紀錄、累積天數與已取得 EXP 不會消失。
- 任務完成後立即鎖定，不能再用第二次點擊直接取消。
- 若真的誤點，可使用「誤點？撤回」，而且必須填寫取消理由才可撤回。
- 撤回後會同步扣回該次完成帶來的 EXP，並重新計算累積與連續天數。
- 完成任務的當下，就立即更新累積天數、連續天數與 EXP。
- 午夜 00:00 只切換到新的一天，不會再自動 +1，也不會重複發 EXP。
- App 持續開著跨過午夜時，會自動更新今天的任務狀態；重新回到 App 時也會檢查日期。

## 既有 V2 功能

- 自律天數無限累加；一天完成至少一項任務即計入自律日。
- 每個任務獨立計算累積完成天數、目前連續天數、最佳連續天數。
- EXP / Level 系統：每級需求逐步增加，Lv.100 起每級固定 2,080 EXP。
- 階級稱號：Lv.1～Lv.100 逐步解放 RPG 式稱號。
- 連續里程碑：7 / 30 / 66 / 100 / 365 天提供額外 EXP。
- 自訂任務可選 1～5 星難度，對應 10～50 EXP；自訂任務每日基礎 EXP 上限 200。
- 舊版資料沿用原本 localStorage key 自動相容。

## 資料

所有資料仍儲存在瀏覽器 localStorage，可從設定頁匯出 / 匯入 JSON 備份。
